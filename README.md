## 🌟 Featured Projects

Here is a selection of my key projects demonstrating my technical capabilities across various domains:

### 1. [RentEasy 🏠 — House Rental Management System](https://github.com/MikiyasAfelew/house-rental-management-system)
A premium, full-featured Mobile and Web Rental ecosystem designed to bridge the gap between renters and property owners.
- **Mobile Client:** Built with **Kotlin, Jetpack Compose, Hilt DI, Room DB, Retrofit**, and **Firebase**. Features real-time price alerts, interactive maps, chat, and native **Telebirr & Chapa** payment integrations.
- **Web Admin Dashboard:** Created with **React + Vite** and Vanilla CSS, enabling seamless user/owner verification, dashboard metrics, and secure authentication flow.
- **Keywords:** `Kotlin` `Jetpack Compose` `React` `Hilt` `Firebase` `Telebirr` `Chapa`

### 2. [OrangeHRM Cypress Automation 🧪](https://github.com/MikiyasAfelew/orangehrm-cypress-automation)
An automated QA and end-to-end testing suite for the OrangeHRM platform.
- **Highlights:** Employs **Cypress** to automate complex admin tasks, user profile changes, recruitment tracking, and core authentication. Integrates Page Object Model (POM) and detailed visual reports.
- **Keywords:** `Cypress` `JavaScript` `QA Automation` `E2E Testing`

### 3. [SentinelScan — Vulnerability Scanner 🛡️](https://github.com/MikiyasAfelew/vulnerability-scanner)
A cyber security scanner application focused on network vulnerability mapping and security reporting.
- **Highlights:** Features a secure user sign-in flow utilizing a database-backed SQLite architecture, user audit logs, and an admin interface to evaluate web application vulnerabilities.
- **Keywords:** `Python` `SQLite` `Security` `Vulnerability Assessment`

### 4. [Android Expense Tracker 📱](https://github.com/MikiyasAfelew/android-expense-tracker)
An Android application to monitor personal finance.
- **Highlights:** Standard MVVM architecture using **Jetpack Compose** for interactive dynamic charts, offline-first storage with Room, and local notification alerts.
- **Keywords:** `Kotlin` `Jetpack Compose` `Room DB` `MVVM`
